# Signature extension X2: proposal experiments

Status: designed, NOT RUN. No result in this file is measured. The runner
(`evals/runners/x2_experiment.py`) is not written yet; it depends on the LLM writer and prompts from
the graph lane. This file will be updated with the measured numbers from `evals/results/x2_experiment.json`
or will keep the "not run" status.

## Design

- Strategy A: `agent/prompts/writer.md`, evidence first (lead with the closest past project and its outcome).
- Strategy B: `agent/prompts/writer_b.md`, outcome and timeline first (lead with the deliverable, date and price logic).
- The same set of bid jobs is split between A and B by a stable hash of the job id, so assignment is
  random with respect to job content and reproducible.
- Outcome: GigSim simulated reply (binary) per submitted proposal.
- Test: two-proportion z-test on reply rate (scipy) and a 95 percent confidence interval on the
  difference. With the small n available in the simulator the test may not reach significance, and a
  non-significant result will be reported as such.

## Limits to state with the result

- GigSim replies are generated by our own simulator, so a difference shows the simulator's reply
  model, not real client behaviour.
- Retrieval quality is held fixed (same variant for both arms) so the experiment isolates the writing strategy.
